# Security Policy for AgentGate AI

AgentGate AI is committed to maintaining high standards of security for autonomous AI systems.

## Reporting a Vulnerability

If you discover a security vulnerability or prompt injection bypass within AgentGate, please do not open a public GitHub issue.

Please report vulnerabilities directly to:
- **Email:** iamhariraj@gmail.com

We will acknowledge receipt within 24 hours and provide regular progress updates during resolution.
